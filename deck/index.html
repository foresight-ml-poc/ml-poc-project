Le terrain de jeu

Un marche predictif, c'est parier sur une question

Sur Polymarket, tu achetes "OUI" ou "NON" a une question. Le prix = la probabilite que la foule donne a l'evenement.

  • "OUI" a 0,41 $ - le marche croit l'evenement probable a 41 %
  • L'evenement se realise - "OUI" vaut 1,00 $. Sinon, 0 $.
  • ~95 % des marches sont binaires (OUI/NON net) ; les rares non-binaires se decomposent en plusieurs paris binaires
  • Volume quotidien > 10 M $ - prix s'ajuste en temps reel

Le probleme

L'heuristique lineaire faite main plafonne a AUC 0.688

La formule heuristique de scoring de Foresight est lineaire : elle additionne 8 features avec des poids fixes a la main. Elle ne voit pas les interactions entre variables.

  • impact x confiance : synergies ignorees
  • multi-source + fraicheur : combo non capture
  • Poids bases sur l'intuition, pas sur la donnee
  • Resultat : AUC 0.688 - winrate ~49 %
L'hypothese

Un modele ML peut-il apprendre ces interactions et depasser le plafond heuristique ?

La solution

Le ML capture les interactions que la formule ignore

Deux branches ML, deux angles d'attaque :

  • Branche A - lift en cross-section : heuristique vs LogReg-8 vs LightGBM sur 26 features. Compare qui predit mieux la meme cible.
  • Branche B - fenetre actionnable : LightGBM entraine sur chaque horizon (10 min vers 1440 min). Trouve quand le signal est le plus predictible.
  • Anti-fuite stricte : allowlist 26 features connues a l'emission
  • Walk-forward 80/20 time-sorted - pas de look-ahead

Reproductibilite complete. Les resultats presentes ne varient pas d'une run a l'autre.
Pourquoi ca compte

Un split melange sur donnees temporelles = look-ahead bias. Tous les chiffres de ce POC sont produits avec walk-forward strict - c'est la garantie que les AUC ne sont pas des illusions.

Lecture

La CV surestime LogReg de 4.8 pts. Le LightGBM, lui, est plus robuste en walk-forward qu'en CV - signe que ses features generalisent bien sur les donnees recentes. C'est le resultat le plus solide du POC.

  • La CV melange passe et futur - le modele "voit" l'avenir pendant l'entrainement
  • Walk-forward = seule mesure honnete sur serie temporelle non-stationnaire
  • LightGBM gagne malgre la rigueur, pas grace a un split laxiste
